# Visual identity

The project uses a deliberate **urban mobility intelligence** visual system rather than default notebook chart styling.

## Brand logic

- **Midnight / deep navy:** analytical depth and executive presentation chrome.
- **Electric blue:** annual members.
- **Coral:** casual riders.
- **Teal:** opportunity, navigation and analytical callouts.
- **Purple / pink:** secondary behavioral signals.
- **Warm gold:** campaign opportunity and decision emphasis.

## Typography

Inter is used where available with large, narrative chart titles and compact uppercase eyebrow labels. Chart titles state the **business interpretation**, not merely the metric being plotted.

## Chart principles

1. One analytical message per visual.
2. Member and casual colors stay consistent across the project.
3. Default axes and borders are minimized.
4. Key ratios are surfaced directly on the visual.
5. Context bands are used only when they help interpretation (for example commute windows and summer months).
6. Every chart is paired with a business implication in the report or README.

## Executive dashboard hierarchy

1. Headline business thesis.
2. Five KPI cards.
3. Seasonality and behavioral-gap panels.
4. Hourly pattern and geographic concentration.
5. Marketing playbook.

The design intentionally resembles a modern BI product while remaining reproducible in Python.
